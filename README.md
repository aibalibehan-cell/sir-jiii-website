## 🚀 Overview

This repository houses the production codebase for the official personal brand and digital architecture portfolio of **Nitish Rock**, Founder of **PatnaHost**.

Engineered entirely from ground zero without third-party page builders, heavy frameworks, or generic templates, this platform showcases 18 production client engagements across industrial manufacturing, fine bridal jewellery, authorized automotive dealerships, healthcare clinics, and digital media enterprises.

---

## ⚡ Core Engineering Highlights

- **Zero-Hydration Sub-Second Speed (<0.8s):** Built with semantic HTML5 and vanilla ES6+ for instant DOM readiness, delivering 98-100 Lighthouse performance metrics on mobile networks.
- **Asynchronous PJAX Navigation:** Powered by Barba.js, providing fluid Single-Page Application (SPA) transitions with hardware-accelerated curtain sweeps and zero white flashes.
- **Physical Kinetics & Magnetic Controls:** Custom GSAP 3 interaction physics with elastic button attraction, momentum scrolling via Locomotive Scroll, and real-time SVG vector doodle draw cycles.
- **Ultra-Responsive Display Range (284px → 4K UHD):** Custom mathematical fluid clamping (`clamp()`) ensuring flawless visual layout across compact mobile devices, foldable displays, laptops, and ultra-wide workstations.
- **Direct Lead Acquisition Pipeline:** Zero-friction inquiry routing leveraging direct WhatsApp Business URI protocol encoding and pre-compiled RFC 6068 mailto payloads.

## 🛠️ Local Development & Deployment

### Local Preview
Because this platform is engineered without cumbersome runtime dependencies or compilation steps, you can serve it with any local static HTTP server:

```bash
# Using Python 3
python -m http.server 8080

# Using Node.js npx
npx serve .
```

Open `http://localhost:8080` in your modern browser.

### Production Deployment
Deploy instantly to any global edge CDN network:
- **Cloudflare Pages / Vercel / Netlify:** Connect repository and set publish directory to `./` (root). No build commands required.
